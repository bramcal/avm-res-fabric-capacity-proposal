# Security

## Reporting a Vulnerability

Report vulnerabilities directly to the repository owner through GitHub. Do not open an issue containing exploit details, credentials, tenant identifiers, or customer data.

After AVM proposal acceptance and creation of the official module repository, use the AVM-managed Microsoft security policy and the reporting channel configured by the owning organization.

## Supported Versions

Only the latest commit on `main` is supported before the first semantic release. No compatibility or security support commitment begins until a versioned release is published.
